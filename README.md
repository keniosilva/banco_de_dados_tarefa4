# Sistema de Orçamentos - Eletrica.com

Banco de dados relacional normalizado até a 3FN para empresa de serviços elétricos.

## Executar os scripts na ordem:
1. `01_criacao_banco.sql` → cria o banco e tabelas
2. `02_inserts.sql` → povoa com dados reais
3. `03_consultas.sql` → 5 consultas complexas com JOIN, GROUP BY, etc.
4. `04_updates_deletes.sql` → exemplos de UPDATE e DELETE com segurança

Testado e funcionando 100% no MySQL 8.0 / MariaDB 10.6+
